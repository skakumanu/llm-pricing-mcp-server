# Security policy

The plain-language security statement, including what this service does and does not have, is published at https://llm-pricing-api.fly.dev/security (source: `docs/legal/SECURITY.md`).

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Ask the support assistant at https://llm-pricing-api.fly.dev/chat?mode=support to escalate a security report; it opens a private escalation in the owner's queue and returns a reference. Do not include working exploit data or other customers' information.

Reports are acknowledged on a best effort basis.
