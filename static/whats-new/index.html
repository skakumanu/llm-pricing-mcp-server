v1.89.0 Nov 1, 2026 Feature
Document writer: decks and one-pagers with provenance, owner-reviewed
Added
  • A document writer for the operator. Ask for one of four documents from a closed catalogue (a pricing comparison deck, a pricing one-pager, a release notes brief built only from this page, or an internal status report) and get a self-contained printable HTML file or Markdown.   • Operator-only: POST /documents/generate, GET /documents/types, GET /documents/artifacts, GET /documents/artifacts/{id} and .../download, plus a Documents panel in the admin console. Each document waits for the owner's publish approval; approving marks it published, rejecting discards it, and it stays downloadable either way. Nothing is sent anywhere
  • The narrative is one bounded model call (claude-haiku-5-5 by default, claude-sonnet-5-5 on request) inside the orchestrator budget. With the budget spent, no key or the backend down, the document is still produced from templates and is visibly labelled “Data-only edition”

v1.88.0 Nov 1, 2026 Feature
Compliance audit: weekly, mechanical, report-only
Added
  • An independent weekly audit of the whole service, for the operator. Every Monday (and on demand from the admin console) the service runs a fixed set of mechanical checks and stores a report: legal placeholders and the legal-live gate, that every database is in the backup configuration, that production secrets are set (names only, never values), version consistency, that the data-quality figures have not regressed since the last report, that the weekly price audit ran, orchestrator budget, old escalations, that every service key is stored hashed, and, when a restricted read-only Stripe key is configured, a reconciliation of subscriptions against local accounts and the webhook registration. Repo-side checks (Dependabot, CodeQL, tracked files) are supplied by a new GitHub workflow

  • The report is evidence, not certification: it contains counts, file and setting names and opaque prefixes, never emails, keys or Stripe ids, and it makes no statement of legal compliance. The audit only reads; it changes no setting, account, subscription or price. An optional one-paragraph summary by a small model is off by default

v1.87.0 Nov 1, 2026 Feature
Your data, your call: export or delete your account; hashed service keys
