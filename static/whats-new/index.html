v1.62.0 Aug 12, 2026 Feature
Repo cost auditor: Batch API, task right-sizing, and duplicate-prompt detection
Added
  • scripts/audit_repo.py now also recommends the Batch API for call sites inside a loop or an offline-looking path (job/cron/pipeline/worker), typically ~50% cheaper for non-latency-sensitive calls
  • New task-based right-sizing check: flags a flagship-quality model used for a structurally simple task (classification, extraction, summarization, translation, rewrite) even when it already clears the cost-savings bar for a model-downgrade recommendation
  • New repo-wide duplicate-prompt detection: flags the exact same prompt appearing at multiple call sites, with a suggestion to extract it to a shared constant and apply caching consistently

v1.61.0 Aug 12, 2026 Feature
New: repo cost auditor — find LLM call sites in your own codebase
Added
  • scripts/audit_repo.py statically scans a Python codebase for LLM SDK call sites (OpenAI, Anthropic, Google, LangChain) and estimates the cost of each one using the same token counting and pricing math as predict_cost
  • Recommends cheaper models and prompt caching where a call site makes that detectable — no credentials or network access to your code required, everything runs locally
  • Run it with python scripts/audit_repo.py /path/to/your/repo; static estimates only, since call frequency can't be known from code alone — pair with GET /usage/summary once deployed for real numbers

v1.60.0 Aug 11, 2026 Feature
New: budget-spend alerts on top of actual usage tracking
Added
  • POST /usage/alerts registers a webhook that fires when actual recorded spend (from POST /usage) crosses a USD threshold — per org, or across all orgs
  • Checked inline after every usage event, not on a schedule, and fires at most once per period_days while spend stays over threshold so it doesn't spam
  • Reuses the same HMAC-SHA256 webhook signing as price-change alerts — one signature format for both
  • New MCP tools: register_budget_alert, list_budget_alerts, delete_budget_alert

v1.59.0 Aug 11, 2026 Feature
New: actual usage/spend tracking — the real-cost counterpart to cost estimates
Added
  • POST /usage and POST /usage/batch record real token usage after an LLM call completes — cost is computed server-side from current pricing, never trusted from the caller
  • GET /usage/summary reports total spend and breakdowns by model and provider, optionally filtered by org
  • Every other tool on this server estimates hypothetical cost from token counts you supply; this is the first one that tracks what you actually spent
  • New MCP tools: record_usage, get_usage_summary

v1.54.0 Jul 28, 2026 Feature
External price oracle — LiteLLM registry as fallback and drift check
Added
  • Unpriced models are automatically filled from LiteLLM's public pricing registry (~2,984 models, MIT licensed), matched by provider so the same model hosted by a different vendor never gets the wrong price
  • A vendored snapshot (data/model_prices_snapshot.json) keeps this working offline or if the upstream registry is unreachable
  • New check_price_drift MCP tool flags curated prices that have drifted more than 5% from the registry — for human review, never auto-applied
v1.53.0 Jul 28, 2026 Feature
Price provenance — every price now knows its own age
Added

  • Additive model discovery — newly-seen models are added as unpriced placeholders instead of being silently skipped until someone hand-types a price
